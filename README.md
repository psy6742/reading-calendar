# 독서 캘린더 (reading-calendar)

아이의 독서 기록을 한글책·영어책으로 나누어 남기는 모바일 웹앱입니다. 단일 HTML 파일(`index.html`)로 동작하며, 설치 없이 브라우저에서 열어 쓰고 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

- 라이브: https://psy6742.github.io/reading-calendar/
- 저장 방식: 각 기기 브라우저의 `localStorage` (`readingCalendar.v1`) — 기기끼리 자동으로 섞이지 않습니다.
- 백업: `⋮ 백업 및 설정`에서 JSON 내보내기 / 가져오기

## 주요 기능

| 탭 | 내용 |
| --- | --- |
| 월간 캘린더 | 날짜별 독서 권수·표지, 전체/한글책/영어책 필터, 아이별 보기 |
| 연간 통계 | 1~12월 독서량 막대그래프(한글책 파랑 · 영어책 빨강) |
| 내 책장 | 전집·자주 읽는 책을 등록해 원터치 기록 |
| 책 추천 / 읽을 목록 | 연령대별 한글 15권 · 영어 15권 큐레이션, 찜 목록 |

도서 검색은 `내 책장` → `지난 기록` → 온라인(카카오 책 검색 · Google Books · Apple Books · Open Library) 순으로 합쳐서 보여 줍니다. 국내 도서 결과를 제대로 받으려면 `⋮ 백업 및 설정`에 카카오 REST API 키를 넣어 주세요.

바코드 인식에 쓰는 `zxing-wasm` 은 스캐너를 처음 열 때 jsDelivr CDN에서 한 번만 받아 옵니다(`cdn.jsdelivr.net/npm/zxing-wasm@2.2.4`).

## 바코드 스캐너 (v2.1 ~, v2.3 정확도 개선)

`+ 책 기록하기` 시트의 `📷 바코드` 버튼으로 책 뒤 바코드(ISBN)를 찍어 책 정보를 바로 채웁니다.

- **2프레임 합의** — 첫 프레임에서 읽힌 ISBN을 바로 인정하지 않고, 최근 4프레임(1.5초) 안에 **같은 ISBN-13이 두 번** 잡혀야 확정합니다. 확정을 기다리는 동안 상태줄에 `확인 중… 조금만 유지해 주세요`가 뜨고 안내 네모가 노란색으로 바뀝니다. 한 프레임만 잘못 읽힌 값이나, 앞뒤 프레임의 값이 서로 다른 경우에는 절대 통과하지 않습니다.
- **두 엔진 하이브리드** — 크롬 내장 **`BarcodeDetector`**(빠름)와 **`zxing-wasm`**(ZXing-C++ WebAssembly, `zxing-wasm@2.2.4`)를 함께 씁니다. `zxing-wasm`은 스캐너를 열 때 jsDelivr CDN에서 지연 로드하고, 실패하면(오프라인·차단) 조용히 `BarcodeDetector`만으로 계속 동작합니다. 반대로 `BarcodeDetector`가 없는 **iOS 사파리에서도 `zxing-wasm` 덕분에 스캔이 됩니다**. 두 엔진 모두 못 쓸 때만 안내 문구가 나옵니다.
- **그레이스케일 + 명암 대비 보정** — 감지용 캔버스의 휘도 히스토그램 2~98% 구간을 0~255로 펴서 비닐 표지 반사·어두운 조명에서도 검은 바/흰 여백 경계를 살립니다(대비가 이미 충분하면 그레이스케일만 적용). `zxing-wasm`은 원본과 보정본을 번갈아 보고, `BarcodeDetector`는 원본을 봅니다(`tryHarder` · `tryRotate` · `tryInvert`).
- **`📸 사진 찍기`** — 스캐너 안에서 `capture="environment"` 카메라로 한 장 찍으면 최대 1600px 고해상도로 원본·대비 보정본을 모두 읽습니다. 정지 화상은 선명하므로 **한 번에 잡히면 바로 확정**합니다. 실시간으로 잘 안 잡힐 때의 마지막 수단입니다.
- 카메라는 `1920×1080`, 후면(`environment`)을 요청하고, 지원되는 기기에서는 **연속 자동초점(`focusMode: continuous`)** 을 켭니다.
- **확대 1x / 2x / 3x / 5x** 버튼, 기본값 **3x**. 기기(하드웨어) 줌을 먼저 당기고, 기기 최대 배율로 모자라는 만큼만 화면(CSS) 확대로 채웁니다.
- 감지는 화면 가운데 안내 네모 영역을 원본 해상도로 잘라 낸 캔버스를 우선 사용하고, 세 번에 한 번은 전체 화면도 함께 확인합니다.
- 미리보기를 톡 누르면 초점을 다시 잡습니다(초점 제어가 없는 기기에서는 거리 안내 문구 표시).
- 조명(손전등)은 기기가 지원할 때만 버튼이 나타납니다.

## 버전 기록

- **v2.3** — 바코드 인식 정확도 개선: 2프레임 합의(같은 ISBN 두 번 = 확정, `확인 중…` 표시), `zxing-wasm`(ZXing-C++ WASM) + `BarcodeDetector` 하이브리드(아이폰 사파리도 스캔 가능), 그레이스케일·명암 대비 보정, 스캐너 안 `📸 사진 찍기`(고해상도 1장 인식)

- **v2.1.1** — ISBN 조회 시작 시 이전 안내 문구 지우기
- **v2.1** — 크롬 내장 `BarcodeDetector` 바코드 스캐너·ISBN 조회 추가
- **v2.0** — 국내 도서 검색(카카오 책 검색) 연동, 설정에 API 키 입력
- **v1.9** — 연령별 추천 도서 150권
- **v1.8** — 연령별 책 추천 탭 · 읽을 목록(찜)
- **v1.7** — 기록 시트의 '내 책장에서 고르기' 칩 목록 제거
- **v1.6** — 바코드 기능 제거(범용 라이브러리 인식률 문제), 내 책장·지난 기록 통합 검색
- **v1.5** — 내 책장(전집 빠른 기록)
- **v1.0 ~ v1.4** — 월간/연간/아이별 보기, 검색·ISBN 도우미, 2배 줌 스캐너

## 배포

GitHub Pages의 배포 소스가 `gh-pages` 브랜치로 잡혀 있으므로, 코드를 고치면 **`main`과 `gh-pages` 두 브랜치에 모두 push**해야 라이브에 반영됩니다.

```bash
git add index.html README.md
git commit -m "..."
git push origin main
git push origin main:gh-pages
```
